# Git Cheat Sheet

A practical, browser-based reference for Git commands used in personal and team workflows. I originally built it as a web-development exercise, and it has grown into a quick reference used by me and several coworkers.

## View the cheat sheet

Open the [hosted Git Cheat Sheet](https://mevorahde.github.io/Git_Cheat_Sheet/) or open `index.html` locally in a browser.

## Topics covered

- Creating and cloning repositories
- Reviewing, staging, and committing changes
- Working with remotes
- Merging and rebasing
- Branches and tags
- Commit history
- Undo and recovery commands
- Practical Git habits

Some commands can discard work or remove files. Read the description, preview changes where possible, and confirm you have a recovery path before running destructive commands.

Corrections and useful additions are welcome through [issues](https://github.com/mevorahde/Git_Cheat_Sheet/issues) or pull requests.
